# NoNlab - 双模颜色同步模块 (Dual Mesh Color Sync)

一个为 VRChat 改模与 Unity 开发者设计的**像素级颜色迁移工具**。无需手绘、无需 Photoshop，在 Unity 编辑器内直接把一个模型的颜色"迁移"到另一个模型上。全自动自适应自组织。

- 当前版本：V1.0
- By-Ninster-NoNlab
- 特点：纯原生 C#，无第三方依赖，双路径支持，像素级精度，604K 像素 / 92ms。

---

## 功能特性 (Features)

- **双路径支持**：顶点色路径（快速）+ 贴图路径（精确），自动适配源模型的数据情况。
- **像素级精度**：贴图路径采用面级反投影 + 3D BVH 查询 + 像素级采样，精度远超顶点级。
- **屏幕取色**：在 Scene 视图里点一下源模型，即可自动获取该点的颜色和采样中心。
- **软过渡**：支持"全染内径" + "渐变外径"的软过渡，消除颜色断面。
- **多线程加速**：像素级烘培，支持多线程加速，604K 像素处理仅需 92ms。
- **源采样范围限制**：可以限制源模型的采样范围，避免远处噪声污染。
- **颜色来源灵活**：支持从源模型材质、手动贴图、手动源色、全局颜色兜底四种方式。
- **非破坏性**：顶点色路径替换 Mesh 引用，贴图路径生成新贴图文件并替换材质引用，均可 Ctrl+Z 撤销。
- **建议**：若需要头部与脖子匹配，输出模式请换到 Texture ，迁移模式换到 Direct Replace 。

### 安装
1. 在 Unity 中打开项目。
2. `Assets` -> `Import Package` -> `Custom Package...`，选择 `.unitypackage` 文件。
3. 导入完成后，在顶部菜单栏找到 `NoNlab` -> `双模颜色同步模块` 打开窗口。

## 使用方法 (Usage)

1. **打开工具**：点击 Unity 顶部菜单 `NoNlab` -> `双模颜色同步模块`。
2. **选择模型**：
   - 将源模型（提供颜色）拖入上方槽位，或选中物体后点"从选中获取为源"。
   - 将目标模型（接收颜色）拖入下方槽位，或选中物体后点"从选中获取为目标"。
3. **选择模式**：
   - **输出模式**：`VertexColor`（顶点色）/ `Texture`（贴图）。
   - **颜色来源**：`Material Texture`（源模型材质）/ `Manual Texture`（手动贴图）/ `Vertex Color`（顶点色）。
4. **调整参数**（详见下方参数说明）。
5. **预览**：点"预览"进行烘焙。
6. **应用**：点"应用"查看效果，走 Undo，可 Ctrl+Z 撤销。
7. **取消**：不满意点"取消"，恢复原状。

### 屏幕取色
在贴图路径下，如果想让结果偏向源模型的某个特定区域：
1. 勾选"手动源色"。
2. 点击"从源模型取色"。
3. 在 Scene 视图里点源模型的任意位置。
4. 工具会自动获取该点的颜色和采样中心。

## 参数说明 (Parameters)

| 参数 | 说明 |
| --- | --- |
| 源材质槽 / 目标材质槽 | 指定要处理的材质槽位（多材质模型） |
| 迁移模式 | `DR`（直接替换）/ `HSL`（色相迁移） |
| 精确模式 | 面级反投影，慢但精确；关闭则走快速顶点插值 |
| 覆盖全部 UV 区域 | 勾上则覆盖整个 UV 区域，不勾则仅覆盖采样成功区域 |
| 乘源材质主色 | 把源材质的主色乘到迁移结果上 |
| 源颜色叠加 | 全局叠加一个颜色，用于整体色调微调 |
| 全局颜色兜底 | 超出影响距离时用源贴图平均色兜底 |
| 手动源色 | 完全使用手动指定的颜色，无视源模型 |
| 软过渡 | 距离越远染色越弱，消除断面 |
| 全染内径 | 内径范围内的像素完全染色 |
| 渐变外径 | 内径到外径之间的像素渐变染色 |
| 限制源采样范围 | 用采样中心而非源表面距离判定采样范围 |
| 采样中心 | 限制源采样范围时的中心点 |
| 多线程加速 | 像素级烘培多线程加速 |
| 影响距离 | 超出此距离的目标像素被跳过 |
| 色调迁移强度 | 最终颜色的迁移强度（0-1） |
| 同时覆盖 A 通道 | 勾上则覆盖目标 Alpha，不勾则保留目标原 Alpha |

## 已知问题 (Known Issues)

- **脸和脖子的接缝适配**：在这类"紧贴"场景下，建议把"影响距离"调大、关闭"法线加权"、降低"混合强度"。
- **仅测试于 Unity 2022.3 LTS**：其他版本理论上兼容，但未逐一验证。
- **目标贴图必须可读**：贴图路径要求目标贴图 `Read/Write Enabled`。工具内置"一键修复"按钮。

---

## 性能 (Performance)

- **顶点色路径**：取决于模型顶点数，通常 10-50ms。
- **贴图路径（精确模式）**：604K 像素 / 92ms（多线程加速）。
- **贴图路径（快速模式）**：更快，但精度略低。
