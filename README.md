# NoNlab - 双模颜色同步模块 V2.5 (VRChat / Unity 用)

⚠️注意⚠️：建议下载v2.5版本


一个可以把一个模型的颜色“刷”，或者说迁移到另一个模型上的工具。
不用手绘、不用开 Photoshop。直接在 Unity 的 Scene 视图里像画画一样刷选，一键完成极高精度的颜色迁移。

---

## 解决什么问题？

- 买来的头发和兽耳，颜色对不上，拼在一起很违和。
- 脸和脖子的接缝处有色差，看着别扭。
- 配饰和素体的颜色不搭，想统一色调但不想手动画。

---

## V2.5 架构升级

1. **笔刷交互**：直接在 3D 视图涂抹。样子是一个亮绿色、圆形的交互光圈，跟随鼠标移动。
2. **GPU 调用**：自研跨管线 Shader，选中顶点瞬间高亮，哪怕几万个顶点也不卡顿。内置高亮上限设置，硬件略差的话也可以开启高亮保护。
3. **极致性能**：多线程软光栅化技术，240万像素的 2K 贴图烘焙仅需约 1 秒。
4. **反白边**：基于 1.0 大修，内置 4 像素 UV 边缘回填（Dilate），完美解决接线处的白边问题。
5. **双路径支持**：顶点色路径（极速映射） + 贴图路径（像素级高保真），自动适配源模型的数据情况。
6. **像素级精度**：贴图路径采用面级反投影 + 3D BVH 查询。实测 240 万像素极速烘焙仅需 108ms（*注：建议 8 核以上 CPU 勾选“多线程加速”以拉满性能*）。
7. **屏幕点选取色**：在 Scene 视图中直接点击源模型顶点，即可拾取该点颜色及采样中心。
8. **正交软过渡**：基于距离或笔刷遮罩的羽化效果，消除生硬的颜色断面。
9. **绝对的非破坏性**：生成全新贴图或网格资产替换引用，全链路支持 `Ctrl+Z` 撤销，绝不污染原资产。
10. **完美兼容**：兼容 Built-in / URP / HDRP 全渲染管线。

## 快速上手 (Quick Start)

**1. 绑定模型**
- 在窗口上方指定 **源模型**（提供颜色的模型，如头发）和 **目标模型**（接收颜色的模型，如兽耳）。
- 也可以直接在 Hierarchy 中选中物体，点击“从选中获取”。

**2. 选择输出模式**
- `VertexColor (顶点色)`：如果源模型有顶点色，选这个，速度极快。
- `Texture (贴图)`：如果源模型只有贴图没有顶点色，选这个，精度最高（像素级）。**我个人强烈推荐不管给谁都用这个，因为它柔。**

**3. 交互刷选 (可选，V2.5重点升级)**
- 如果只想给局部染色，点击 **“✏️ 开始刷选”** 进入 3D 笔刷模式。
- **左键** 涂抹选中，**Alt + 左键** 擦除，**Ctrl+Z** 撤销。
- **注意！** 如果不刷选，工具会默认处理整个模型。

**4. 调整参数**
- 根据需求调整“影响距离”和“过渡宽度”（消除生硬边界）。
- 如果是贴图路径，建议保持“边缘膨胀”默认 4 像素（防 UV 接缝白边）。

**5. 一键执行**
- **顶点色路径**：点击“👁️ 生成预览”确认效果 -> 点击“💾 应用到原模型”或“📦 另存为资产”。
- **贴图路径**：点击“🔥 烘焙并生成贴图”，工具会自动生成新 PNG 并替换材质引用。
- *所有操作均支持 `Ctrl+Z` 撤销。*

---

## 核心功能特性

- **双路径**：顶点色快速映射 + 贴图像素级 HSL 色彩迁移。
- **软过渡**：全染内径 + 渐变外径，消除生硬的边缘断面。
- **绝对安全**：支持一键预览，非破坏性替换，随时 Ctrl+Z 撤销。
